## What the tests show

- Export of a built scene returns the built layout on both canvases within 0.0005 of the canvas, the same bindings, types,
  overlay files and canvas query, and the project is deep-equal before and after.
- Round trip in memory and on disk: a layer moved in the studio shows at the new place in the exported package and in the
  re-imported new scene; the earlier built scene is untouched; devices created 0, changes 0, removes 0; overlay entries reused.
- Edit: input package unchanged; new id, lineage, `(edited)`; chat query width/height follow the box; game keeps its shape and
  its crop; camera crop within `maxCrop`; swap trades the boxes; off-canvas, too small, unknown layer or op, missing canvas size,
  same-layer swap and a bad edit after a good one all throw and return nothing; a V layer outside the safe zone warns.
- Variants: same seed = identical packages, another seed differs; 4 distinct variants on H and V references, each schema-valid
  and importable with the existing state unchanged; across 3 seeds x 2 references x up to 6 variants every box is on the canvas,
  V layers inside the safe zone stay inside, overlap never grows, the game's crop is unchanged; nudges stay within 0.2 of a canvas
  side (distance reported per variant); mirror is the exact left-right flip.
- CLI: flag off exits 2 and writes nothing; build -> import --apply -> export -> edit -> variants -> import dry run, with the
  project file byte-identical after export, edit and variants; never over an existing file; bad arguments exit 1.
