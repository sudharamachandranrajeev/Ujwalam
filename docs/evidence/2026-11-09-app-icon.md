# App icon (2026-11-09)

Problem: no icon on shortcuts, taskbar, studio window or exes.

Design: rounded-square tile in the violet-night accent family (gradient #a472ff to #6a38d6; theme accent #8650f0,
accentHi #b18cff) with a white-to-pale-gold four-point spark ("Ujwalam" = radiant) and a soft halo. No brand,
channel or private term. Preview: `docs/evidence/2026-11-09-app-icon-256.png` (checked by eye at 256 and 32 px).

Reproducible: `node tools/make-icon.mjs` (stdlib only; procedural supersampled drawing, PNG via node:zlib, ICO with PNG
entries 16 20 24 32 40 48 64 256). Output is deterministic; the test compares the committed .ico to the generator.

Applied:
- `app/studio/res/ujwalam.svg` (source), `ujwalam.ico`, `res/png/ujwalam-{16,24,32,48,64,256}.png`.
- `app/studio/res/ujwalam.rc` linked into `ujwalam-studio.exe` and `ujwalam-start.exe` (`app/studio/CMakeLists.txt`).
- `QApplication::setWindowIcon` in `app/studio/src/main.cpp` (PNGs embedded as `:/icon/`, so no imageformats plugin
  is needed); covers the main window and every dialog.
- `tools/package/Install-Ujwalam.ps1`: copies `ujwalam.ico` to the install root, both shortcuts set `IconLocation`.
  `build-alpha.mjs` stages `ujwalam.ico`; `manifest.mjs` allowlists it.
- Web control page: `ui/favicon.svg` plus `<link rel="icon">` in `ui/index.html` (served locally, CSP `img-src 'self'`).
- Host exe: not changed (optional).

Evidence: `node --test tests/package-alpha.test.mjs` 17 pass, 0 fail, 1 skip (full-build E2E needs the OBS runtime).
New tests: .ico structure and sizes, equals generator, allowlist, shortcut IconLocation read back via WScript.Shell,
and both built exes carry RT_GROUP_ICON + RT_ICON (PE resource directory read). Studio built into the worktree's
own `out/studio/build`.
