## 3. End-screen rule (pack 0.2.2)

User correction, 2026-10-27: a match can show more than one end screen (Domination shows both MVP and Impact Play).

- Every end screen that appears is detected: MVP (M1), Impact Play (M2), FINAL KILLCAM (K1).
- The profile name is checked on each screen separately.
- Each screen with the name is positive, but counts once per match for scoring. Every named screen is listed as a reason.
- No screen with the name means no signal. No screen is required to appear.

Data: `endScreenRule` in `data/games/codm/detectors.json` (0.2.2, changelog in `$comment`), schema `$defs/endScreenRule`. The fusion step (G3, P2b) consumes the rule; until then it is data with schema tests.
