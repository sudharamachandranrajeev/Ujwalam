## Host facts found while building (needed by P2/P6)

- `obs.dll` is delay-loaded. The host prefixes `PATH` with `<runtime>/bin/64bit` before the first libobs call. `SetDllDirectory` is not enough, because libobs `os_dlopen` resets it after each module load.
- Plugins start helper processes from the **host exe's** directory (`os_get_executable_path_ptr`). `obs-ffmpeg-mux.exe`, `obs-nvenc-test.exe`, `obs-qsv-test.exe` and `obs-amf-test.exe` must sit next to the host. Without `obs-nvenc-test.exe`, obs-nvenc does not register its encoders (CreateProcessW error 2). POST_BUILD copies them.
- GPU pinning: the host exports `NvOptimusEnablement` and `AmdPowerXpressRequestHighPerformance`, and selects adapter 0 by default. Log:
  ```
  Adapter 0: NVIDIA GeForce RTX 4050 Laptop GPU
  Adapter 1: Intel(R) UHD Graphics
  Loading up D3D11 on adapter NVIDIA GeForce RTX 4050 Laptop GPU (0)
  ```
- NVENC: `[obs-nvenc] NVENC version: 12.2 (compiled) / 13.1 (driver), CUDA driver version: 13.50, AV1 supported: true`. Encoder ids available: `obs_nvenc_h264_tex`, `obs_nvenc_hevc_tex`, `obs_nvenc_av1_tex` (plus `_soft`, `_cuda` and the legacy `jim_*` / `ffmpeg_nvenc` aliases).
- Writes: libobs and module config go to `<out>/module-config` (`obs_startup` module config path). Nothing was written to `%APPDATA%\obs-studio` or `C:\Program Files\obs-studio`.
- Network: `rtmp-services` and `win-capture` contact obsproject.com at startup (services.json / compatibility.json update). Observed connection to 37.59.185.111:443.
