## Decisions and reconciliation

- **Profile location.** The amendment said `data/games/<game-id>/profile.json`. The profile now in use is one file, `data/profile.local.json` (template `data/profile.example.json`), with `games.codm.{ign,variants,clan_tag}`. The schema follows the in-use shape; the amendment's per-game profile path is superseded. Detector packs stay at `data/games/<game-id>/detectors.json`; `games.<id>` in the profile selects the pack. Optional `default_mode` (mp/br/auto) and `capture_canvas` (H/V/both) added to the game profile for G4. The amendment doc itself was not edited.
- **Detector ids.** M1–M4, B1 as in the amendment. New: M5 (MP kill feed), X1 (multi-kill / killstreak card, both modes), B2 (BR own-kill counter), N1 killcam and N2 downed/redeploy (role `negative`, weight must be null).
- **Per-mode ROIs.** Each ROI is a fraction of the detected game area (cropdetect 1566:1080:176:0, about 1.45:1). A ROI with `mode` applies only to that mode; X1 has one for MP and one for BR.
- **Weights, windows, cooldowns, OCR min confidence, name-match min score** are `null`. G3 proposes them from labelled data; no invented values.
- **Suppression** is a pack-level rule: `suppress_medals_in_replay` hides M3 and M4 while M2 (Impact Play / REC replay) is shown.
- **Versioning.** Pack carries `version`; `engineVersion` records the detector-engine function version it targets.
- **Detection record privacy.** `ocrText` and crops can hold other players' names; `cropPath` must be relative under `cache/` or `docs/evidence/private/` (both gitignored). A suppressed record must name its rule (`suppressedBy`). A required name match must be a boolean, not null.
- **Labels.** `windowStartSec`/`windowEndSec` are seconds on the session timeline; `sessionId` pattern matches `data/sessions.json` ids and tests check the fixture id exists there. `label` is keep/reject; `rating` 1–5 only on keep. JSON Schema cannot compare two fields, so end > start is checked in tests and must be checked by the A6 writer.
