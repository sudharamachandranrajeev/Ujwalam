# A0-D1: the app opens and the previews show game, cam and overlays (20 minutes or less)

Status: READY once you say "devices ready". Needs:

- the capture card with the game running on it;
- the facecam and the mic connected;
- Meld and OBS closed, so the devices are free;
- the host built (`node app/host/tools/build.mjs`).

Evidence of the run without devices: `docs/evidence/2026-11-03-a0-alpha-shell.md`.

## Before you start (once, about 3 minutes)

1. In `data/profile.local.json`, fill in these keys. The Default H scene needs them and stops with the key name if one is missing:
   - `brand.wordmark` and `brand.character`: image files, relative to `paths.profile_assets`;
   - `handles.twitch`, `handles.youtube` and `handles.kick`;
   - `links.discord`.

   `paths.profile_assets` is optional. Without it, image paths are relative to the legacy overlay folder.
2. Optional: pin a device to a role, if the automatic match picks the wrong device or none. Add this to the same file:
   `"devices": {"roles": {"facecam": {"path": "<device path>"}}}`.
   The roles are `game-capture`, `facecam` and `mic`. Prefer `path` over `name`: every string in the profile becomes a private term for the git hooks.

## Steps

1. Run `npm run alpha -- --allow-devices --mock`.
   - Add `--rebuild-alpha` if an earlier run built the project without devices. The terminal then says "built without devices and is loaded unchanged". The old file goes to `projects/_old/`.
   - `--mock` feeds the overlays with mock chat. Nothing reaches Streamer.bot or any platform.
2. Read the terminal. Expected:
   - three `role` lines for `game-capture`, `facecam` and `mic`. Each says `bound (preset <preset id>)`, `bound (override-path)` or `bound (override-name)`, or `not bound: <reason>`;
   - `alpha project built` (or `loaded`);
   - `overlay server: running; event feed: on; child has the event token: yes; browser layers allowed`.
3. Look at the two native preview windows, H (960x540) and V (540x960). Expected in H:
   - the game picture from the capture card;
   - the facecam;
   - the Default H overlays: wordmark, event list, goal bar, counters, subscribe pill, ticker and character.
4. Check V. Until the V preset is added, V stays empty, and the terminal warns `scene-default-v.json not found`. Note what you see.
5. Fire a test overlay event. With `--mock`, mock chat arrives every second. Watch the chat overlays and chat-driven effects in H for 10 seconds.
6. After 10 seconds the terminal prints this line: `overlay feed after 10 s: <n> overlay page(s) connected, <n> chat and <n> event frame(s) delivered, <n> effect(s)`. Expected: the chat count is above 0.
7. Open the control page from the browser tab the launcher opened (`http://127.0.0.1:<port>/`). Check that it loads, and note what it shows.
8. Click in the terminal and press Ctrl-C to stop. Expected: the previews close, and the host log ends with `exit 0`.

Also send the path of the host log. The terminal prints it as `host log: ...`, under `<dataDir>/logs/host-<stamp>.log`.

Do not paste screenshots in chat: they show your face and viewer names. Keep them in `docs/evidence/private/`.

## If something fails

- A role says `not bound: no connected device matches ...` or `... connected devices match ...`: pin it with `devices.roles` (step 2 of "Before you start"). Then run again with `--rebuild-alpha`.
- `profile is missing placeholder key(s): <keys>`: fill in those keys, then run again.
- The host does not start: send the last 30 lines of the host log.
